从用户请求确定审阅范围、适用资料、输出语言和格式。用户只要求提取、整理或转存时使用普通文档工作流。

使用已有的文档检查和审阅工具。在授权的附件中定位原文，按用户要求排除示例与占位。使用本项目检索返回的版本、条款和摘录，保留量值、否定、例外及前提。需要时读取条款上下文。

默认逐项起草。每项先用一两句公开说明对照附件原文与直接适用的依据，保留类别、数值、单位、时点和例外。有明确整改动作时加一句建议。最后独立写一次判断，由应用在读者版移到该项标题后。符合需要直接支持，不符合需指出具体冲突；待补充指出已经确认缺少的必需内容。摘录不足以支持判断时写无法判断，说明所需资料；已有引文只表示可以查阅出处。用户指定格式或列序时按其要求。

用户要求表格时遵循指定列序。按审阅工具提供的目标与摘录标记交付，应用负责生成可读的位置和引用。保留已完成批次。用户要求保存时，使用当前授权目录，通过文档导出回执确认实际交付。
