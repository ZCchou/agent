## 实施中发现及裁决

- Q8 的无工具收尾会丢掉原文句号。裁决：模型可返回明确的位置引用，由应用从已核验读取证明回填原文；如果模型主动提供错误原文则仍拒绝，未知、重复、乱序引用也拒绝。大选择集使用不可伪造猜测的完整选择指纹，不把全部正文塞回模型。
- Q8 完成核对曾在 `satisfied` 中凭空新增 DOCX 交付物。裁决：已满足核对只验证既有目标；修订目标必须明确返回需要工作或补充信息，不借已满足状态新增义务。已有原始请求核对仍执行。
- 一轮六次实测中前五次成功，第六次照抄协议示例的数量二，而原请求要求五。已删除数字示例锚定，规划独立记录用户声明数量并与执行选择器核对；模型不能把数量不一致的规划当作通过。六次验收重新执行，旧轮不记为通过。
- 独立审查发现项目导入模板被附件专用收尾拒绝，及目标修订后沿用旧提取契约。已分别保留 Host 授权项目来源的既有完成路线、按目标修订更新收尾契约，并补回归。
- 审阅结果完整正文保存在受管产物，恢复后从已校验产物重建展示，不依靠十项预览重建全文报告。报告和审阅证明关联证据代次，资料变化后旧证明不能计入新完成数；历史结果保留。
