# OCR 预览版离线安装与发布计划

沿用已确认的 Windows 单用户离线部署方案，发布到 ZCchou/agent 的独立预览 Release。运行组件超过 NSIS 和 GitHub 单附件容量限制时，使用小型安装器及多个标准 ZIP，安装器读取同目录 ZIP 完成校验与安装。

## 交付边界

- 版本标记为 v0.15.0-ocr-preview.1，应用标识继续使用 io.github.zcchou.agent.ocrpreview。
- 使用当前已验收的预览程序构建，记录其调试构建及签名状态，自动更新关闭。
- 安装器包含 Host、Core、文件哈希和离线校验脚本。组件 ZIP 包含 llama.cpp、RAG、OCR、OCR 模型及固定版本微软离线依赖。
- 对话主模型仍由用户本地导入。发布资产排除用户数据库、业务原件、原页图片及本机测试 JSON。
- 每个 ZIP 保守控制在 1.7 GiB 未压缩内容以内，逐卷和逐文件校验，缺卷或损坏时拒绝安装。
- 安装与卸载复用既有事务机制，OCR 组件使用独立所有权标记，用户数据目录独立保存。

## 执行步骤

1. 增加分卷规划、公开资产白名单和 ZIP 解压边界的失败测试。
2. 为既有安装脚本增加显式 OCR 组件选项，保留原有安装调用行为。
3. 实现同目录 ZIP 校验与受管暂存解压，编译 NSIS 用户级安装器，写入独立卸载信息和快捷方式。
4. 运行发行工具回归和本机安装、版本检查、OCR 组件检查及卸载验证。干净机验收单独记录。
5. 固定来源提交，生成 SHA-256 清单，推送预览分支和标签。
6. 建立 GitHub 预览 Release，上传每个资产，核对远端资产大小及摘要后发布。
