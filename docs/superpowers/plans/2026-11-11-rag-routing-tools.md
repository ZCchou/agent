# 适航智能体请求分流、强制 RAG 与本地执行实施计划

本文件落实用户批准的五阶段计划。默认自动分流，强制 RAG 在当前对话持续生效。RAG 场景开放任务需要、模型已验证、项目已授权且运行策略允许的工具，覆盖文件、Skill、隔离终端和文档生成。

## 任务 1 稳定基线、迁移与请求分流

- 收敛预算快照兼容回归并保存源码、应用及数据库备份。
- schema 28→29，IPC 21→22，工具契约 v3→v4，构建 ID 为 schema29-rag-workflow-v1，同步全部兼容性检查。
- 保存会话 rag_mode auto/required，运行捕获请求模式、有效策略和原因。派生及复制继承模式，重试恢复沿用原运行模式，编辑发送采用当前模式，幂等请求校验包含模式。
- 纯寒暄和普通问题直接回答，具体条款、版本、符合性、依据资料填写模板及 rag.required Skill 强制证据。混合消息按完整任务处理，短确认结合待执行任务判断。
- 强制按钮按会话持久化，新聊天默认自动。缺项目、资料库、索引或证据时保留输入和附件并显示处理入口。

## 任务 2 工具与隔离终端

- 工具集合按任务、模型能力、项目授权、运行策略交集计算，移除 RAG 的文件工具统一过滤。
- 复用原生及结构化工具探测、现有目录授权、审批模式、变更集和审计。
- Windows AppContainer 无网络能力，授予项目、工具与临时目录访问。进程挂起创建，绑定隔离和 Job Object 后启动；取消、超时、退出、撤权回收进程树。隔离不可用明确报错，文件和文档工具独立工作。

## 任务 3 文档工作流

- document.inspect_template、document.fill_template、document.export，支持 DOCX 段落和表格，输出 DOCX/Markdown/TXT。
- 文档二进制受管存储，执行记录保存描述和哈希。字段保存正文、证据、缺项与复核状态。
- 纯文本模型由执行器完成明确的文档输出任务；通用自主工具调用使用已验证模型能力。
- 写入经现有授权文件流程发布，验证文件后报告完成，返回打开文件及目录入口。

## 任务 4 证据与结果

- 专业内容、进度、工具结果分别采用对应契约。专业判断逐项关联实际采用的证据，应用填入来源、修订版、条款号和物理页码。
- 版本差异、未回答字段、资料缺口和无法确认支持关系的结论进入复核清单，专业草稿保留人工复核状态。
- 执行、重试、恢复和发布继续校验授权、模板身份和证据状态，文件完成依据执行结果。

## 任务 5 验证与交付

- 自动/强制分流、持久化、缺资源、多资料库、撤回、跨项目、文件写入、纯文本导出及工具调用回归。
- DOCX 表格、中文路径、冲突、取消和恢复，终端 PowerShell/子进程/直接 IP/HTTP/DNS 隔离及文件访问测试。
- 完整请求预算、Python、前端、Rust、浏览器和离线构建回归。
- 本机用现有试验大纲模板填写振动试验目的，核对条款、原文、物理页码、DO-160G/F 差异及缺项，保存可打开 DOCX。关闭强制模式后“你好”直接回复。
- 交付独立预览更新文件、验证记录与可回退备份。保留现有未提交改动。
