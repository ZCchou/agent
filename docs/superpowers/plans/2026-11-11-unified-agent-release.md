# agent 统一版实施计划

用户已授权实施及发布，基线为已验收 Document Preview .5，源码回退提交 b3086f5。按 executing-plans 逐阶段执行，最后进行一次独立全量审查。

## 已确认的目标和约束

- 产品 agent，标识 io.github.zcchou.agent.airworthiness，版本 0.16.0-preview.1，GitHub ZCchou/agent 预发布。
- 扩展语义意图识别，普通寒暄走快速路径，其他自动任务使用所选本地模型参与 RAG、附件、工具、文档需求识别。强制 RAG 和 Skill 证据要求由执行器执行。
- 每运行一次分类，输入上限2048 token，输出256 token，就绪后超时30秒。保留用户请求、附件用途和待执行任务，裁剪历史。无法判断时返回明确待确认状态，专业任务采用证据约束。重试复用已保存意图，编辑重新识别。
- 全应用统一公共 Button/IconButton/按钮组，常规32px、紧凑28px、聊天工具栏36px，同组一致。Lucide统一图标、语义样式、禁用原因、键盘及窄窗支持。
- 合并 OCR Preview、Document Preview 数据。相同ID及完整业务关系一致时合并，冲突及必要父项目按来源分别保留。重写结构化关联和受管引用，原件/模型按哈希去重。
- 模型独占文件转移至选定磁盘，先复制校验、目标发布成功后清理旧位置。共享文件复制。迁移可取消、恢复、回退，旧数据先生成快照。punkagent使用独立标识、目录、更新源和签名，检查碰撞与共享模型。
- 手动检查更新，应用更新包括Host/Core/DLL/辅助更新程序。运行环境、OCR模型、GGUF与RAG权重由离线组件或模型导入处理。更新清单及程序包签名必需，预发布允许安装器无Authenticode。
- 在线更新只能访问独立发布源，业务执行继续离线。复用草稿恢复和程序事务替换，健康检查失败回退。旧预览版一次手动安装迁入统一版。
- schema30、IPC23、构建schema30-agent-unified-v1、工具v4。增加迁移管理及意图结果/更新状态接口。
- 构建与测试大型暂存放F盘专用目录，防止C盘耗尽。源码和发布资产排除模型权重、业务数据、私钥和个人附件。

## 阶段及接口

1. 基线与语义路由。扩展现有意图JSON为task_kinds、rag_requirement(required/not_needed/uncertain)、文件/工具需求、承接任务、来源/原因；统一消费并记录rag_decision。先测试隐含业务、组合任务、超时/坏JSON，再接正常发送、重试及Skill。
2. UI公共控件。公共Button尺寸/状态、IconButton/按钮组及全页面替换；测试同排尺寸、禁用/忙碌状态、900x500/1002x723、高DPI与中英文长标签。
3. 应用统一及迁移。独立产品身份，源探测、预览、任务启动/状态/取消/继续/恢复；快照升级合并、ID图映射、文档/附件/证据/模型文件与授权迁入。源进程占用检查和可恢复模型转移。迁移前显示来源、冲突和空间。
4. 签名程序更新。独立airworthiness-preview清单，复用签名验证、草稿、事务替换；小型ZIP+受管辅助更新器，兼容组件检查及安装后健康验证。独立本机更新密钥，公钥入产品，私钥排除Git。
5. 全量验证及发布。Python/前端/Host/浏览器/原生NSIS、旧版合并与恢复、本机RAG模板DOCX及寒暄、程序更新与回退；release模式内嵌前端。完整安装器及离线组件每资产<=1.5GiB，程序更新包、签名/校验/说明。提交并推送源码、发布GitHub预发布、更新README。
