## 本轮工程取舍

- 采用独立预览分支、应用标识与数据目录，保留稳定部署可并行使用。
- 本次交付便携调试包，依赖本机已有 WebView2。干净机安装器验收另行安排。
- OCR 首版使用 CPU。CPU 根据资源使用一或两个 worker，本机本次实际为一个。OCR CUDA 和持续双 worker 压力验收继续保留。
- 采用 200 DPI 和页级缓存，轻量摘要与机器识别快照承载首版。高级区域编辑、人工修订审阅数据库和重启后自动调度继续保留。相同原件重新导入可以复用已完成页。
- Paddle 原生权重在本机中文路径下加载失败，受管 ASCII 路径加载通过。中文用户名和其他路径需进一步验证。
- 保留整页方向识别，关闭重复表格方向识别。通过官方开关关闭存在库内错误的单元格二次 OCR，使用整页文字匹配表格结构。复杂表格的关系需要原图核对。
- 项目自动采用权限使用当前 Core 生命周期内的绑定修订令牌，用户后续更改绑定会使该任务令牌失效。未来实现重启调度时，需要同步持久化授权边界。

当前运行组件状态表示找到了可执行文件，首次使用前再做完整哈希校验。已存在但损坏的组件会在加载时报告错误。
