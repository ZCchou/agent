# Windows x64 本地离线安装

将完整离线 ZIP 解压到空间充足的本地磁盘。保持安装程序与 `payload` 文件夹在同一级目录，退出正在使用的 agent 及其模型进程，双击安装程序。如果取得的是单个内嵌安装程序，可以直接运行。

安装程序校验文件大小和 SHA256，并安装本地提供的 Microsoft VC++ x64 与 WebView2 先决组件。安装后，`ocr-runtime` 包含 CPU 版 OCR 运行库，`ocr-model-package` 包含 PP-StructureV3 的版面分析、文字识别和表格识别模型。安装包还包括 llama.cpp 与 RAG 运行组件。

主语言模型、嵌入模型与重排序模型使用用户选择的模型库。在应用的模型设置中配置这些模型。用户数据、项目和用户导入的模型保存在各自的配置目录中。

升级前请关闭当前应用并保留足够空间，以便安装器暂存新组件和保存旧组件。包内 `release-manifest.json` 记录本次构建与签名状态，`SHA256SUMS.txt` 记录随附文件的校验值。
