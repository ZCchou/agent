# 0.17.0-preview.1

## 后台执行

任务在后台持续运行，聊天展示阶段、计数、耗时和取消入口。活动未知时继续观察，确认故障后最多自动恢复两次，持续失败时保存结果并展示具体原因及重新尝试入口。重启后优先恢复工具检测，再恢复依赖它的请求。

模型文件和运行组件按有效文件身份复用校验。辅助 worker 切换及内存回退保留监控身份，CUDA 资源允许时嵌入与重排同时驻留，资源不足时按最近使用情况回收空闲 worker。

## 意图与工具

寒暄使用快速路径，其他任务保留本地模型意图识别。确认需要证据后建立检索阶段和准备辅助模型。模板批次缩小时复用适用证据。

首次需要本地工具或询问执行能力时，自动检测模型的原生或结构化工具调用能力。结果按模型、模板、引擎与探针身份保存。应用提供实际工具清单，纯文本模型沿用应用托管的文档操作。

## 交互与诊断

澄清弹窗使用独立布局，长问题、选项、中文路径和多行输入在内容区滚动。建议选项与自填草稿独立保存，关闭重开后保留当前任务的回答。

模型与设置页面集中提供本地配置。更新器独立提供联网检查与下载。诊断页面可以打开日志目录并导出关联任务的阶段时间线。

## 升级

数据库 schema 33，IPC 26，设置 schema 20，worker v2，工具契约 v5。升级沿用应用数据与程序备份机制。安装器按应用身份及语义版本处理旧清单，支持 0.16 到 0.17 的差异安装。

本次辅助推理运行组件发生变化，0.16 用户使用完整离线安装包升级。将安装器和发行页列出的全部分卷放在同一目录。校验一致的旧分卷和已安装文件可以复用。

完整安装器尚无 Authenticode 签名。程序更新包和公开更新清单使用既有独立密钥签名。
