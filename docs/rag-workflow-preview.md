# 请求分流与文档工作流预览版

## 使用方法

项目对话默认使用自动分流。纯寒暄直接生成回复，具体适航条款和模板填写会预先取得资料库证据。输入框的“强制 RAG”在当前对话持续生效，重启后恢复。新对话默认自动模式，复制和派生对话继承来源模式。

1. 在项目设置中启用已就绪的资料库，并授权本地工作目录。
2. 选择已导入的本地对话模型。发送时应用自动加载所选模型。
3. 上传 DOCX，并将附件用途选为“待填写模板”。
4. 明确指定章节和问题，例如要求填写“振动试验”的“试验目的”，并保存为“振动试验目的.docx”。输出路径使用中文或英文引号包围，填写项目内相对路径。
5. 应用读取模板、检索资料、检查引用并生成文档。文件操作遵循项目现有审批模式。
6. 文件发布成功后通过“打开文件”查看结果。需要查看原文时打开对应证据。

未指定输出位置时，应用使用项目根目录中的“适航草稿-运行编号”文件名。已有文件冲突会进入现有文件变更校验流程。DOCX 段落和表格单元格支持回填，DOCX、Markdown 和 TXT 支持导出。其他 Office、WPS 和 PDF 附件沿用已有读取流程。

纯文本模型可使用应用管理的明确文档导出。原生或结构化工具模型在能力验证通过后，可以调用当前项目已授权的文件工具、Skill 和隔离终端。

## 证据与复核

应用生成来源、修订信息、条款号、原文摘录和物理页码，发布前重新检查证据状态。模板引用标准与资料版本存在差异时，生成复核事项。未提供的设备信息及未回答事项保留为待补充内容。

结论支持检查采用保守规则，能够提示部分未被摘录覆盖的概念。改写和专业判断保留人工复核状态，专业人员需要确认条款适用性及结论支撑关系。

## 终端范围

Windows 终端使用无网络能力的 AppContainer 和 Job Object。当前项目与专用临时目录获得所需访问权限。项目中的硬链接和重解析路径会阻止隔离终端启动，正在独占使用的文件不授予终端访问权限。项目目录扫描上限为十万项，恢复清单上限为 16 MiB。

隔离测试覆盖实际 PowerShell、子进程、TCP、HTTP、UDP 接收和显式 DNS 解析调用。每次命令结束后回收进程与授权，异常退出遗留的记录在下次启动隔离终端时恢复清理。

## 升级与回退

本版使用 schema 29、IPC 22 和工具契约 v4。升级前自动备份数据库，历史会话迁移为自动分流，历史证据及索引继续保留。

增量 ZIP 适用于生成包时记录的 Document Preview 基线，运行前核对旧程序和运行组件哈希。解压后退出应用，运行 UPDATE.cmd 并选择原程序目录。更新器备份三个程序文件后替换，更新中断时再次执行同一更新包恢复。

程序回退需要同时恢复旧程序与对应代际的数据库备份。预览构建未签名，业务资料与模型存放于现有应用数据目录或用户选择的存储位置。
