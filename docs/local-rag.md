# 本地适航资料库使用说明

## 准备模型

打开“系统功能 → RAG → 辅助模型”，选择模型库存放磁盘，再选择嵌入和重排序模型的完整目录。选择包内主文件时，应用授权并检查其所在目录。模型配置、分词器、权重分片和 ONNX 外部数据应保持原有相对位置。

原始 safetensors 支持 Qwen3-Embedding-0.6B、Qwen3-Reranker-0.6B、BGE-M3 和 bge-reranker-v2-m3。ONNX 支持按应用约定适配的两种 BGE 包。导入后点击加载测试，状态可用后用于资料库。详细约定见 [模型格式说明](rag-models.md)。

CPU 为默认设备。选择 CUDA 后进行实际加载检查，设备或显存错误会显示在页面中，可手动切换 CPU。

## 建立项目资料库

1. 在 RAG 资料库页创建资料库，指定嵌入与重排序模型。
2. 选择 DOCX、文本 PDF、TXT、Markdown 文件，或粘贴条款。任务列表显示进度及失败原因，运行任务可取消。
3. 预览片段和原文定位，填写名称、修订版、文件编号及来源，核对解析警告后确认。
4. 为每份文件选择一个已确认版本，构建候选索引。构建失败时保留现有索引。
5. 选择项目并绑定资料库。项目绑定一个索引快照，后续重建通过“采用当前索引”显式更新项目所用版本。

扫描 PDF 需要先完成 OCR。复杂表格、阅读顺序和文本框的解析问题会标为待校核，确认记录保留人工核对选择。

## 问答与证据

项目对话在生成前检索绑定快照，自动安排条款精确检索、中文词法检索、向量检索和重排序。嵌入模型改变后需重新构建索引，已有项目快照继续保留其原模型指纹。

生成模型使用数值回环地址的本地服务，例如 `http://127.0.0.1:1234/v1`。RAG 运行禁用环境代理、公网检索、远程图片及终端工具。解绑资料库后，含有既往 RAG 内容的历史对话和复制分支继续执行本地限制。

首次启动安装 `airworthiness-clause-qa` Skill，可在消息中显式使用 `$airworthiness-clause-qa`。该技能要求已绑定资料库。`rag.search` 和 `rag.read` 遵循当前运行的项目范围、调用预算及审计。

回答通过本轮已装入上下文的证据编号、原文摘录、文件哈希和版本检查后显示。点击引用可分页查看原文及定位，资料撤回后立即拒绝新检索与原文展开。引用一致性检查覆盖出处和摘录，专业判断保留为待复核草案。

## 运行组件与构建

开发机使用 Python 3.12 x64。Core 的构建依赖与辅助推理依赖分别安装。CPU 组件按以下命令构建和暂存。

```powershell
./tools/build-rag-runtime.ps1 -Device cpu
python tools/rag_runtime_bundle.py .artifacts/rag-runtime-cpu/rag-runtime --destination apps/agent-desktop/src-tauri/binaries/rag-runtime --repository .
```

发行脚本会暂存完整组件目录并放入 Tauri 资源及便携输出。组件清单记录全部文件哈希、worker 源码和设备依赖锁身份，过期缓存会阻止发行并要求重建。CPU 组件约占 3.5 GB，复制和首次校验需要时间及额外暂存空间。

完整发行包默认随安装器携带 CUDA 版运行组件，同一套组件提供 CPU 和 NVIDIA CUDA 两种执行方式。应用默认选 CPU，用户可在辅助模型页切换 CUDA。用户端安装、加载运行组件期间均使用随包文件。

打包机预先准备 `build-rag-runtime.ps1 -Device cuda` 生成的目录，或在发行时通过 `-RagRuntimeDirectory <目录>` 指定已有目录。发行校验要求完整包使用 CUDA 组件，CPU-only 组件会被拒绝。CUDA 执行需要电脑已有兼容的 NVIDIA 显卡驱动。CPU 精简包通过 `release-windows.ps1 -RagRuntimeDevice cpu` 显式选择。

构建机首次准备依赖时需要可用的依赖源或预装构建环境。已有组件目录会直接校验并打包。模型权重由用户从本地文件导入。

## 验证范围

自动化测试覆盖模型目录校验、适配数值、取消与恢复、文档结构、索引原子切换、版本隔离、引用校验及本地运行限制。真实 Edge 测试覆盖资料库及模型配置操作，原生文件选择和后端采用测试替身。

CPU 冻结组件使用微型生成模型和合成 ONNX 图验证适配器、中文路径及标准输入输出协议。完整官方模型权重、CUDA 实机、十万条 1024 维端到端性能、进程出网监测及最终安装器验收需要目标设备继续验证。现有十万条检索实验使用合成 64 维向量，其结果只代表该测试配置。

解析目前在受限后台线程执行。文件大小、解压规模、文本量、片段数和用时均设限，取消或超时后的结果不能写入资料库。原生 PDF 调用在执行期间无法强制中断，操作系统级单任务内存隔离仍待补充。
