## 配置 F 盘数据目录

在启动程序的同一进程环境中设置 `AGENT_PROFILE_DIR` 为绝对目录，例如 `F:\AgentData\io.github.zcchou.agent.airworthiness`。目录末级名称须保持应用身份，以兼容现有更新及恢复流程。

WebView 缓存使用 `WEBVIEW2_USER_DATA_FOLDER` 指定目录，临时文件使用 `TEMP` 和 `TMP` 指定目录。本机模型库在模型页面单独指定。迁入已有数据前应保存数据库及配置备份。

## 安装和核验

运行 setup.exe 前，将安装器与全部七个 offline.partNN.zip 放在同一目录。核对 usb-copy-list.json 和 SHA256SUMS.txt 后安装。程序更新包附独立签名，具体适用的运行组件以包内 application.json 为准。
