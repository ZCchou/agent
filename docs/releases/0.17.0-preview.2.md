# 0.17.0-preview.2

## 本地任务编排

- 在模型准备前保存原始任务，支持独立修订处理步骤、资料范围和交付物。
- 已验证原生或结构化工具调用能力的本地项目模型，通过智能体循环理解请求并采取首次动作。
- 增加本地能力发现、计划更新和执行中澄清工具。读取附件后可以补充问题，明确答复后继续原任务。
- 纯文本模型继续使用应用托管的附件和文档处理能力。
- 根据完整请求预算选择当前工具定义，后续可动态发现并启用已授权能力。

## 文档审阅与生成

- DOCX 清单覆盖正文、嵌套表格、页眉页脚、脚注尾注、文本框和内容控件文字。
- 图形、公式及嵌入对象进入待处理清单。
- 文档审阅作为独立工具返回结果，可以接续修订、填写和导出。
- 按章节和输入预算拆分审阅批次，复用已核验结果，并对跨章节参数差异组织回读比较。
- 附件分页位置保持稳定，改变本轮读取预算后继续读取同一位置。
- 完成检查核对已声明的资料范围及实际发布文件。技术失败位置保留未完成状态，重试重新处理失败批次。

## 进度与兼容

- 聊天任务详情展示原始目标、处理步骤、覆盖情况和资料缺项。
- 执行中澄清复用现有弹窗，保留建议选择、自填草稿及关闭重开状态。
- 数据库升级至 schema 34，IPC 升至 27，用户工具契约升级至 v6。
- 设置 schema 20、辅助 worker 协议 v2 延续使用。
