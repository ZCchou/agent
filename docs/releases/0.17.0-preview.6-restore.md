# preview.6 升级与恢复

本地候选。专业全文审阅、27B及3090验证尚未完成，暂不公开发布。

1. 保留preview.5安装文件、所有分卷、程序目录及对应数据库/配置备份。候选安装器和全部分卷必须放在同一目录，按usb-copy-list.zh-CN.txt拷贝。
2. 退出旧应用后运行候选完整安装器，选择原统一版安装目录。安装事务仅处理登记的受管文件。不要把候选包解压覆盖用户模型原件。
3. 正式启动前由现有迁移机制备份数据库；schema35/36迁至37，Host/Core/前端一起升级。程序包仅适用于运行组件清单一致的安装，其他情况使用完整包。
4. 若迁移或安装失败，保留诊断及原备份。不要反复覆盖数据库；安装事务可按安装器提示恢复。应用未运行时再恢复旧程序和升级前同一时点的数据库/配置。
5. 回退preview.5不能直接读取升级后的schema37数据库，必须同时使用preview.5对应备份。用户模型外部路径及原件保持不变。

旧失败任务重新识别用户范围；显式全文目标保留，已发布文件及完成审阅保留。实际来源、解析视图或证据变化会作废相应完成证明，恢复不重放已确认写入。

Ed25519签名和SHA256校验结果见候选文件夹交付报告。未进行正式配置NSIS安装时，验收报告会明确标注，不以隔离助手测试代替。
