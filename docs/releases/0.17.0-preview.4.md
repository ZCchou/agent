# 0.17.0-preview.4

## 模板与上下文

- 模板检查明确要求附件标识、既有模板标识和项目路径三选一，各字段说明取值来源。参数纠正向模型指出具体限制。
- 工具目录刷新复用已启用能力，新的目录替换旧目录调用在本轮上下文中的副本。执行记录继续可查。
- 完整请求接近输入容量时，动态调整本轮回复预留空间，保留最低回复容量。
- 文档、检索与 Skill 工具返回依据实际调用和剩余容量分页提供。
- 证据取得前的附件读取使用读取约束，专业结论要求实际可用证据。

## 条件不满足时的说明

- 界面显示实际错误，本地模型接收原始请求、确认的原因及操作结果记录，并给出处理情况和下一步说明。
- 缺少资料库的请求先保存到对话，再展示条件缺口和模型说明。
- 说明回复使用独立文本调用，任务及业务步骤保留失败状态。资料发生变化时，模型可根据错误记录解释当前处理情况。
- 用户取消和应用中断分别记录。说明调用失败时保留原错误及应用诊断。
