- 附件不再要求预选用途，提供默认本地文档技能与按需工具发现。
- 工具完整结果受管保存，可分页回读；长输入使用原始来源和游标处理。

## 验收与使用

候选版用于本机验收，不自动发布更新源。Qwen3.8-27B-UD-Q4_K_M 尚未下载，27B及3090实机兼容验收仍待实际文件与设备测试。原有本地模型、项目与附件不随安装包附带或删除。

升级前由应用保存数据库备份；回退需要同时使用对应旧程序及旧数据库备份。完整包需将安装器和全部分卷放在同一目录。源码只推送新分支，不合并。
