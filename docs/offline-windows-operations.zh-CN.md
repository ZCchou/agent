# Windows 全量离线安装与迁移

此交付件为 `UNSIGNED LOCAL VERIFICATION` 本机验证构建。安装器的实际 Authenticode 状态、源码工作区状态、跳过的测试、安装冒烟结果见 `release-manifest.json`。正式公开发布继续执行干净源码、测试、安装验证与签名门禁。

## 安装

1. 单 EXE 交付件可直接运行。若交付件为完整 ZIP，请解压至本地磁盘，保持安装 EXE、`payload` 文件夹、清单和说明位于同一目录，避免直接在压缩包预览窗口中启动安装。
2. 退出 agent 及其托管推理进程，运行 `agent-版本-windows-x86_64-offline-local-setup.exe`。安装界面可查看组件校验和复制日志。
3. 安装器使用自身内嵌的清单 SHA256 验证全部离线组件，然后运行 Microsoft VC++ x64 离线运行库与 WebView2 Evergreen Standalone 离线安装器。系统权限提示来自 Microsoft 前置组件。如提示重启，完成重启后使用应用。
4. 应用的“本地模型”页面分别导入主模型与辅助模型。模型权重由用户另行提供。主模型导入支持的 GGUF 文件，辅助模型导入页面所要求的完整模型目录。

安装资源包含同一 llama.cpp 固定源码版本的 CPU、CUDA 12.4 和 Vulkan 引擎，以及 CPU/CUDA 辅助推理运行时。GPU 驱动由目标电脑提供。用户无需安装 Python、CUDA Toolkit 或设置模型服务地址。

解压空间和目标安装盘空间应分别预留完整组件大小。安装器在目标盘额外检查一个完整组件副本加 1 GiB 余量。升级保留上一版本资源用于恢复，因此还应保留旧版本占用空间。ZIP 解压、暂存和安装副本会同时占用磁盘。

## 完整性与来源

`payload/payload-manifest.json` 列出全部组件的相对路径、字节数和 SHA256。清单本身的 SHA256 固定在安装 EXE 内，替换旁边的清单不能改变该安装器允许的组件。安装器拒绝额外文件、缺少文件、修改内容、目录链接、路径穿越和 Windows 路径别名。

`runtime-provenance.lock.json` 固定上游 llama.cpp 压缩包、共同源码提交、上游发布地址、许可证及 Microsoft 前置组件。`llm-runtime/runtime.json` 记录每个引擎的原生版本输出和文件哈希。`rag-runtime/runtime.json` 记录工作进程、模型配置及依赖锁的源码身份。辅助运行时的 `third-party-licenses/inventory.json` 列出实际构建环境依赖及随附许可证，CUDA 再分发许可随组件附带。

`SHA256SUMS.txt` 和 ZIP 旁的 `.sha256` 可供传输后复核。未签名构建的哈希用于检测传输或存储损坏，其发布者身份应通过可信交付渠道确认。

## 升级与故障恢复

安装目录中的 `llm-runtime` 与 `rag-runtime` 为应用托管资源。请保持其中的文件完整。安装器先在 `.managed-runtime/versions/随机事务号` 中建立新组件并逐文件验证，再通过同盘目录重命名激活两个组件。

复制或激活失败会恢复旧目录。中断后，下次安装首先恢复未完成事务，然后重新验证本次交付。旧组件和失败现场保留在受所有权标记保护的版本目录。请退出托管进程后重试原安装包。空间不足时应先扩展空间。

如果校验失败，请重新从可信交付渠道复制完整 ZIP 后解压到新目录。安装器会拒绝升级正在使用中的托管进程或无法重命名的活动文件。安装器不会下载缺少的组件。

## 既有数据迁移与卸载

升级保持应用标识与既有用户数据位置。已有 SQLite 数据库由 Core 按 schema 25 迁移。用户数据库、项目文件、模型库和审计记录位于用户数据目录，安装事务只操作应用目录内的托管运行时。

原先的外部模型配置进入显式迁移状态。请在本地模型页面导入对应的主模型和辅助模型，并使用页面提供的确认流程完成配置。迁移失败时保留原数据和错误记录，修复问题后重试。

卸载前退出应用。卸载器检查托管进程及当前组件完整性，删除经过所有权和清单确认的应用运行时，并清理本次安装产生的版本暂存。用户数据与模型库由用户继续管理。已修改或混入额外文件的托管目录会使卸载中止，需先检查变更。

## 验证范围

本交付流水线提供工具单测、真实文件锁与事务中断恢复测试，以及隔离目录中的本机安装、Core 握手、解析模式、运行时校验和卸载验证。最终执行情况以交付清单和 Task 5 报告为准。干净 Windows 虚拟机验证和正式代码签名属于后续发布门禁。
